Waar gebruik ik AI voor?

Ik gebruik AI vooral voor de CSS van mijn website. Het skelet van de website heb ik zelf gemaakt, maar voor de vormgeving gebruik ik AI om de website er mooier uit te laten zien.

Ik denk dat AI erg handig is, omdat het mij veel tijd bespaart. Ik leer er ook veel van. Als er iets misgaat op mijn website, kan ik aan AI vragen wat het probleem is en hoe ik dit kan verbeteren.

Dat vind ik handig, want mijn leraar is natuurlijk niet altijd beschikbaar, terwijl ik aan AI wel op elk moment een vraag kan stellen. AI kan mij ook stap voor stap uitleggen wat ik moet doen en waarom.

Ik probeer zelf ook te begrijpen wat ik verander, zodat ik er iets van leer. Ik vind AI daarom een goede toevoeging bij dit soort projecten. Het helpt mij niet alleen om mijn website te verbeteren, maar ook om meer te leren over HTML en CSS.
